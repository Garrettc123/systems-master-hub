## 🚀 Quick Start

### Prerequisites

```bash
# Required
- Git 2.30+
- Docker 20.10+ & Docker Compose
- Python 3.11+
- Node.js 18+

# Optional (for full deployment)
- Kubernetes 1.24+
- Terraform 1.5+
- AWS/GCP/Azure account
```

### Local Development

```bash
# Clone the repository
git clone https://github.com/Garrettc123/systems-master-hub.git
cd systems-master-hub

# Start core systems with Docker Compose
docker-compose up -d

# View logs
docker-compose logs -f

# Check system health
curl http://localhost:8080/health  # API Gateway
curl http://localhost:9090         # Prometheus
curl http://localhost:3001         # Grafana
```

### Deploy Specific Categories

```bash
# Deploy core infrastructure
cd 01-core-infrastructure/
# Follow README.md instructions

# Deploy AI/ML platforms
cd 02-ai-ml-platforms/
# Follow README.md instructions

# Deploy business automation
cd 04-business-automation/
# Follow README.md instructions
```
